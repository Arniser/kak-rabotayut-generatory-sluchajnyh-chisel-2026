<h2>2. Какие 5 ключевых компонентов формируют работу RNG?</h2>

<p>Архитектура системы генерации опирается на строгие математические и технические элементы. Каждый компонент выполняет критически важную функцию.</p>

<ul>
	<li><strong>Зерно (Seed):</strong> Начальное значение, запускающее алгоритм. В качественных системах оно формируется из атмосферного шума или термодинамических процессов.</li>
	<li><strong>Математический алгоритм:</strong> Формула, преобразующая зерно в последовательность. Стандартным решением выступает алгоритм &laquo;Вихрь Мерсенна&raquo; (Mersenne Twister).</li>
	<li><strong>Источник энтропии:</strong> Физический процесс, обеспечивающий истинную случайность для инициализации зерна.</li>
	<li><strong>Модуль хеширования:</strong> Криптографическая функция, скрывающая внутреннее состояние генератора от внешнего наблюдения.</li>
	<li><strong>Система валидации:</strong> Механизм независимого аудита, подтверждающий соответствие выдаваемых чисел статистическим тестам (например, NIST SP 800-22).</li>
</ul>
